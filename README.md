# Portfolio numérique

Site web étudiant pour le module Digital Skills et les unités associées, conforme à la structure du guide fourni.

## Utilisation

1. Ouvrir `index.html` dans un navigateur ou utiliser Live Server dans VS Code.
2. Remplacer les champs entre crochets par vos informations.
3. Tester et documenter vos propres réalisations : captures, vidéos, podcast, carte mentale, PowerPoint narré, sources.
4. Créer un dépôt GitHub public nommé `portfolio-numerique`, y envoyer les fichiers.
5. Dans GitHub : Settings > Pages > Deploy from a branch > main / (root) > Save.
6. Le site sera disponible à `https://azizbaraketTI13.github.io/portfolio-numerique/` après publication.

## Modules

Digital Skills (cybersécurité, prompt engineering, création de contenu), développement (Python, C, algorithmique), systèmes (OS, architecture et électronique).

## Technologies

HTML5, CSS3, JavaScript, GitHub Pages, notebookLM, HeyGen, Canva, CapCut, Gamma.

## Transparence IA

ChatGPT ,notebookLM, HeyGen, Canva, CapCut, Gamma ont aidé à produire cette base et les exemples pédagogiques. L'étudiant doit tester, adapter, vérifier et compléter ses productions réelles. Les exemples de prompts ne sont pas des résultats expérimentaux. Les fichiers multimédias ne sont pas inclus.
