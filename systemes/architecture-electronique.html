Architecture simplifiée d’un ordinateur

PROCESSEUR (CPU) ↕ Bus de données / adresses / contrôle ↕ Mémoire RAM ↔ Entrées / Sorties ↔ Stockage

Le processeur exécute les instructions, la RAM conserve temporairement les données, les périphériques permettent les échanges et les bus transportent les informations.

Binaire et hexadécimal
