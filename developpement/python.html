Projet 1 — Calculatrice

Objectif : calculer une somme à partir de deux nombres saisis. 

a = float(input("Premier nombre : "))
b = float(input("Deuxième nombre : "))
print("Somme :", a + b)

La fonction input lit une valeur, float la convertit et print affiche le résultat.

Projet 2 — Devinette

secret = 7
essai = int(input("Devine le nombre : "))
if essai == secret:
    print("Bravo !")
else:
    print("Réessaie !")

Le programme utilise une condition pour comparer la réponse à la valeur attendue.

Projet 3 — Moyenne de notes

notes = [12, 15, 17]
moyenne = sum(notes) / len(notes)
print("Moyenne :", moyenne)

Une liste conserve les notes ; sum calcule leur total et len leur nombre.
